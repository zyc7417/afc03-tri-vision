# 三路采集的像素处理 RTL

这里提供三路演示位流中用于灰度转换、拼图滤波和同帧受限均衡的寄存器传输级源码。板上运行的位流构建号为 `20261103T000535.103108Z`，SHA-256 为 `fb5604d323514b606a02680336023b84853512aae1d53a1a078ac9bd36c8e023`。

| 文件 | 在系统中的作用 |
| --- | --- |
| `rtl/quad_board_raw10_gbrg_half_gray.sv` | 将每路摄像头已接收的 RAW10 像素按 2×2 GBRG 单元转成灰度，同时传递帧身份、行尾和帧尾标记。 |
| `rtl/gaussian_gray4_bram_sp.sv` | 用两块行缓存和当前行构造 3×3 高斯窗口。拼图接缝处取本视角的边缘像素，避免跨画格滤波。 |
| `rtl/histogram_equalize4_pipeline_r1.sv` | 对当前帧并行统计，建好 256 项查找表后读回同一帧映射。默认模式将原值与均衡值按 3∶1 混合，并限制灰度变化不超过 16 级。 |
| `rtl/histogram_lane_bank_bram_mux.sv` | 存储一条像素通道的直方图计数，供均衡模块实例化。 |

## 运行离线验证

准备 Python 3 和 Icarus Verilog。确保 `iverilog` 和 `vvp` 位于 PATH 中，或用 `IVERILOG` 和 `VVP` 环境变量指定程序位置。在本目录运行：

```sh
python sim/check.py
```

脚本对灰度转换、高斯滤波模块做编译与展开检查。均衡模块通过项目台架模拟写入统计、外部帧回读和输出背压，并将输出像素与参考计算对比。五组尺寸为 16×12、9×7、32×24、1×1 和 1920×4。`sim/original.sv` 是用于逐周期比较的原均衡参考实现，仅参与仿真。

## 板级工程

完整演示链还使用 FMC_VID007 子卡、安路 PH1A90SEG324、DDR3 控制器、PCIe 端点和 SGDMA 接口 IP。竞赛提交代码包含完整 TD 工程及本次 SRAM 位流。使用相应配套 IP 的环境需要安路 TD Release 2026.1 SP2 和厂商提供的器件库。公开目录的仿真只依赖上表中的 RTL 和本目录的台架。
